29 October 2026. Apple M5 Pro / arm64 / macOS 27.0. Runtime scope: desktop Chrome; no broad device certification. [Implementation and remaining scope](2.0.0-FEATURES.md) · [Security review](2.0.0-SECURITY.md) · [Before/after gallery](screenshots/2.0/index.html).

Browser tests include 320/540/1280 px video views and a 360px popup, 2× CDP scaling emulation, reduced motion, generated bright/dark media, fullscreen **player container**, multiple videos/hidden ads, language/metadata filtering, same-element source changes, media replacement, preparation pause/cancel/failure/retry/checkpoints, inert hostile subtitles, keyboard Escape/focus, bounded word cards, deletion, real vocabulary flashcard dialog, paired bilingual SRT without a model, both-direction English visibility, Watch/Learn behavior, finite speed restoration and shadowing. Other practice types are covered in pure helper tests; no local-voice audio output or all-device hearing check is claimed.

Real model example: English “I want to drink coffee.” produced **我想喝咖啡。**, with pinyin **wǒ xiǎng hē kāfēi**. Chinese fixture retained Hanzi/pinyin and produced an English rendering containing “I'd like to have coffee.” These are observed outputs, not a broad accuracy score. Linguistic regression assertions are developer-curated; an independent native Mandarin reviewer did not evaluate this release.

Chrome reported two transient translator-creation failures during the final genuine-model run before the existing retry control succeeded. The UI disclosed the failure and kept the local-only policy. Language-pack setup is therefore not guaranteed to succeed on the first click, even on this tested Mac.

## Measured performance and compactness

- Default fixture subtitle block: **54.39 CSS px high**, width 171.34 px. Hover 120 × 54.09 px; pinned 217.03 × 93.09 px. Opening either leaves subtitle top/height unchanged; toolbar remains hidden.
- Actual-model default subtitle height: **54.39 px**. This is not a universal maximum for arbitrary captions/custom font sizes.
- Paused original local video, extension active, translation double: **20.004 seconds** sampled with CDP Performance metrics; renderer task-duration increase **0.024475 seconds**, observed renderer JS heap **11,162,936 bytes**. This is page/renderer evidence, not total Chrome/model RAM, whole-system CPU or a memory-leak benchmark.
- Synthetic timestamp lookup: 52,500 samples, p95 0.000209 ms in Node v24.13.0. It excludes translation/rendering. See raw results for timings and sample definitions.
- 30/60/120-minute timelines are tested through **accelerated timestamp lookup and seeks**, not real-time playback. Actual wall-clock 30-, 60- and 120-minute sessions, whole-browser CPU/RAM growth and ASR performance were not run. No results are invented.

## Security and data

No new permission or runtime npm dependency; no capture, application networking, accounts, advertising or tracking. The new event-driven worker serializes local writes and rejects stale saves after deletion. All learning data/preferences are deleted except a random revision tombstone needed to reject late writes. Exported files and Chrome-managed model packs are separate. Cache failures display a session-only warning; cancellation retains the correct line denominator. See the source review for controls, remaining risks and test boundaries.

## Acceptance gaps and scoped limitations

YouTube public page loaded but exposed no usable captions/transcript in this session; see [site observation](2.0.0-YOUTUBE.md). That observation did not run the extension. Successful captioned YouTube, YouTube SPA navigation, Shorts, cross-origin players, PiP/native video-only fullscreen, genuinely long/fast live videos, physical display scaling, slow hardware, Windows/Intel Mac/Linux and poor-connectivity model downloads remain unverified. Local fault doubles cover failures and unsupported API, but do not certify actual offline/poor-network downloads.

Offline transcription stays disabled with a [feasible future approach](../docs/OFFLINE_TRANSCRIPTION.md). Existing bilingual HTML tracks are not auto-paired. No reliable preparation ETA is claimed. Dictionary/grammar coverage, unfamiliar names and tone sandhi remain limited and disclosed. Subtitle source line breaks normalize to spaces. No absolute security, privacy, translation or pronunciation guarantee is made.

## Reproduce

`npm test`; `npm run check`; `npm run simulate`; `npm run test:browser`; `npm run test:real-extension`; `npm run build`. Real-model tests can download browser-managed packs and use an isolated temporary profile. Tests require the documented local Playwright runtime/Chrome setup; the shipped extension does not require Node or Python. Run website server on port 5184 and `node tests/site.cjs` for static-site checks.
