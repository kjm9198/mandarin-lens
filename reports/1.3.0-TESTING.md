# Mandarin Lens 1.3.0 — compact overlay validation

29 October 2026. This release responds to the oversized stacked word-card/toolbar layout. It changes the actual overlay, rather than only its website copy or ZIP size.

## Layout changes

- The word explanation is a fixed, anchored popover outside the subtitle layout. It no longer expands the caption block or moves captions when opened.
- Hover shows only Hanzi, pinyin and meaning. Actions appear only when pinned; sentence context expands only on request. The large white card, instructional hint and redundant native word tooltips are removed.
- The permanent branded toolbar is replaced by a small explicit `···` control. Caption hovering does not reveal toolbar/preparation controls. Opening controls dismisses word-card clutter; keyboard Escape and focus restoration remain available.
- Compact defaults are 12px Hanzi, 18px pinyin, 12px English, zero background opacity, lighter pinyin weight, tighter spacing and a lower subtitle position. Comfortable/Large and custom appearance controls remain available.
- Exact previous default appearance settings migrate once. Custom sizes and vocabulary are preserved; selecting Comfortable later is not silently migrated again.

## Regression evidence

17 engine tests pass, including a pure migration regression covering old defaults, custom sizes and already-migrated settings. Syntax/manifest/permission/CSP/source-pattern checks and `git diff --check` pass.

26 packaged Chromium checks pass on Chromium 156.0.8078.4, with no page errors. The test copy receives disclosed test-only localhost permission and an inert discovery worker. The shipped ZIP/manifest remain unchanged. Deterministic UI tests use an explicit Translator double, not a claimed quality benchmark.

The browser test seeds actual extension storage with the previous default appearance and an existing vocabulary entry, verifies migration and preservation, then checks that deliberate custom font choices survive reload. Actual pointer hover and click open the word popovers. Geometry assertions verify unchanged subtitle top/height and a hidden toolbar before/after hover and pinning. Explicit toggle opening/closing and 320/540px viewport bounds are verified. Existing playback, loop, source-change, malicious-text, retry/resume, cache clearing and deletion tests remain.

On the original local fixture, the Compact subtitle block measures about **187 × 54 CSS px**; hover card **120 × 54 px**; pinned card **150 × 83 px**. The subtitle top coordinate is unchanged when either card opens. These are measurements on this fixture/browser, not a universal maximum for arbitrary long subtitles or expanded context. Larger/custom presets intentionally differ.

A separate installed-Chrome test uses actual on-device translation in the isolated extension world, owner-authorized language-pack downloads, both translation directions, preparation, seeking and cleanup. It also checks Compact geometry with an actual translated word and captures a real-model crop. Its final result/hash is recorded alongside this report. Screenshots from deterministic UI testing and actual-model testing remain distinguished.

No permissions, remote code, cloud processing, capture capability or runtime dependency were added. Popup now loads the already packaged core helpers for appearance migration. The new local marker is an ordinary layout version preference. Security checks are an internal development review, not an independent audit.

Broad public-site compatibility, long-session resource behavior, mobile, native picture-in-picture and independent linguistic accuracy remain outside these focused checks. Earlier synthetic-session results remain separately labeled baseline evidence. No real beta feedback was invented.
