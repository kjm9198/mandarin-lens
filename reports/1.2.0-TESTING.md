# Mandarin Lens 1.2.0 validation

28 October 2026. This release focuses on media/caption selection and recovery. Earlier version reports retain their original hashes and limitations.

## Changes

The extension selects among up to 32 rendered video candidates using viewport area, fullscreen, playback and a small preference for the current selection. This is a heuristic, not automatic ad detection or a guarantee of a user's intended player. Hidden players are excluded; scrolling a selected video out of view alone does not require forgetting it when no better visible player exists.

Live native subtitles exclude metadata and declared wrong-language tracks, prefer explicit matching languages and selected tracks, normalize text as inert content, and bound track/cue enumeration. DOM-caption fallback is scoped to the selected player/parent rather than the whole document. The first 32 track/cue candidates are considered. Unknown-language tracks remain a fallback; language labels supplied by the site can be wrong.

Changes to the selected media element, its source attribute/current source or its stream invalidate imported/prepared captions and generation-sensitive work even when the page URL stays unchanged. Video/source insertion and removal are observed so element replacement is detected without waiting solely for the periodic fallback. Native media loading events handle source changes. General multi-player and site behavior remains heuristic.

A live model rejection exposes Start learning again, and a preparation rejection saves its completed prefix before exposing the retry path. Retry uses a user action, preserving Chrome's model activation rules. Old no-caption status is dismissed when a new caption arrives. There is no automatic cloud fallback or background model download retry.

## Verification

`npm test`: 16 pure engine tests passed, including new selection, fullscreen/tie preferences, offscreen fallback, live track language/kind filtering and inert text normalization.

`npm run test:browser`: 22 packaged Chromium checks passed on 156.0.8078.4 with zero page errors. The actual ZIP is extracted; a temporary test-only manifest adds localhost access and an inert discovery worker. The shipping manifest and ZIP remain unchanged. The deterministic harness explicitly substitutes the Translator, uses an original local WebM, and places a hidden video before the visible player. Active metadata and French captions coexist with matching English captions to test source selection. Tests switch the same media element's source and replace its element at the same page URL, verifying old imported/prepared transcripts are cleared. Explicit model rejections test live retry and preparation checkpoint/resume. Existing looping, seeking, Escape, malicious-text rendering, cache-only clearing and data deletion checks remain.

`npm run test:real-extension` is separate from simulated rendering tests. It exercises actual Chrome Translator downloads and both translation directions inside the extension's isolated world, including preparation, media seeking and cleanup. The owner previously authorized these model downloads. Its final result and package hash are recorded alongside this report.

`npm run check` and `git diff --check` pass. No runtime dependency, permission, cloud call, telemetry, remote executable code or capture feature was added. Static checks and internal source review are not an independent security audit. The prepared-cache storage/deletion controls remain unchanged from 1.1.

The previous 10,000 synthetic engine journeys remain separately labeled baseline evidence, not human feedback or new provider-compatibility validation. No new timing, CPU or memory benchmark is claimed. Public captioned YouTube/Shorts, broad hardware/browser support, picture-in-picture, long-session behavior and independent translation/pinyin quality remain unverified. Audio transcription remains unimplemented.
