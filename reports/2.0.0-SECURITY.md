# V2 security and privacy review — 29 October 2026

Scope: application JavaScript, MV3 manifest/CSP, subtitle parser, worker message boundary, popup, vocabulary/import/export, packaging and shipped dictionary provenance. This is a maintainer source review with automated regression evidence, not an independent penetration test or certification. No P0/P1 issue was established in the reviewed final paths. Browser/OS/model internals and hostile extension/browser-profile compromise are outside this review.

## Fixed issues and evidence

| Issue | Cause and change | Regression evidence |
|---|---|---|
| Concurrent saves could overwrite another tab's words | Read/modify/write lived independently in tabs. New event-driven `storage-worker.js` serializes fresh reads and writes; patch operations preserve other additions. | Worker test sends 25 concurrent saves; concurrent reviews use the newest review; actual vocabulary-page browser journey. |
| A late preparation or word save could repopulate deleted data | In-flight work could outlive clearing. Durable random `dataRevision` and `cacheEpoch` tokens reject prior-session writes. Delete signals close overlays before clearing. | Worker deletion/cache-clear races, rejected stale writes, actual browser deletion closes overlay; only random revision marker remains. |
| Imported metadata could retain private URLs or unbounded history | `learning.js:cleanEntry` allowlists fields, safe source IDs and numeric ranges; review history is capped at 100 per word. | URL rejection and bounded review tests. Only optional `youtube:VIDEO_ID` is saved; no full URL is needed. |
| Word saving could take context from a later caption | A pinned card outlives the current line. Selection captures Chinese/English example and timestamp when pinned. | Source inspection; broad timing combinations are not exhaustively tested. |
| Async caption import or native track change could retain stale captions | Import now checks generation/video/URL after reads and cache waits; native preparation fingerprints caption language/mode/count/endpoints. | Existing same-element source/replacement tests; native-track fingerprint is additionally source-reviewed. |
| English visibility could hide the wrong layer in Chinese→English | Added a separate English visibility flag while retaining legacy source-caption preferences. | Packaged browser checks both directions and bilingual direction remapping. |
| Canceled preparation could report a zero denominator / cache failures were silent | Preserve total before invalidating and surface a session-only cache warning. | Cancellation denominator assertion plus existing resume tests; cache warning path source-reviewed. |
| Shadowing boundary could erase its chosen caption | Playback crossed the timed cue's exclusive end before hiding English. It pauses just inside the chosen interval and restores speed. | Actual-media shadowing and finite replay tests. |

## Verified controls

- `manifest.json`: only activeTab, scripting and storage; no host/capture/history/microphone permissions, no external messaging or automatic page injection. Temporary test localhost access is not in the distribution ZIP.
- Extension-page CSP remains `script-src 'self'; object-src 'none'; base-uri 'none'; connect-src 'none'`. Runtime JS/data is packaged; no fetch/WebSocket/remote executable fallback or eval. The worker is event driven, with no recurring tasks or network code.
- `storage-worker.js:8`: sender ID and allowlisted action checks; destructive/editor actions additionally require the extension-page URL. Messages are size bounded; prepared records validate cues/translations and use a restricted hash-key namespace. No window.postMessage bridge accepts webpage commands.
- Imported subtitles/dictionary/meanings/grammar use textContent and DOM construction, not HTML sinks. Malicious encoded subtitles remain inert in packaged-browser tests. SRT/VTT files are limited to 2 MB each / 4,000 cues; vocabulary files to 2 MB / 500 words, with allowlisted fields.
- `vocabulary.js:safeCell`: CSV and Anki TSV neutralize formula-leading cells; JSON backup is data only. Object URLs are revoked after downloads. DOM-based exports/imports do not introduce remote services.
- Prepared cache writes are serialized, bounded to three records and an approximate 4 MB UTF-16 estimate. Hashes prevent storing raw URL cache keys but do not encrypt the caption values. Cache-only clearing keeps words/settings.
- Local speech requires a browser-reported localService Mandarin voice; missing voices fail clearly. No SpeechRecognition, tab capture, microphone upload or pronunciation assessment is present. Transcription remains disabled.
- Lifecycle cleanup removes observers, event listeners, timers and overlay; destroys translation instances; cancels speech; invalidates preparation; restores finite-replay speed. Paused preparation waits for an explicit resume/cancel signal, without a recurring pause timer.
- Zero third-party npm runtime dependencies. Selected CC-CEDICT data includes full license, attribution, generator and source checksum. Historical ICU data's precise original generator/version remains unknown and is disclosed.

## Remaining risks and limits

Local storage is not encrypted. Profile access, exports, website controls and the browser's own model-download infrastructure have separate risks. A localService flag is the browser's report, not a separately audited network guarantee. Chrome/OS dependencies are not security-audited here. SHA-256 checksums detect changed artifacts only when the expected checksum is trusted.

Revision tokens reject stale saved vocabulary/cache; arbitrary tab crashes, disk quota failures, extension upgrades and same-word stale editor conflicts are not exhaustively enumerated. Shared vocabulary edits preserve the latest review metadata; changing a word's spelling concurrently with another review can still need manual reconciliation. Deletion retains only a random revision tombstone to prevent resurrection; exported files and Chrome language packs require separate deletion. A fully adversarial browser-profile/extension compromise is outside the protection boundary.

No absolute security/privacy claim, native-language correctness certification, automatic ZIP update or Chrome Web Store review is implied. See the QA report for tested and untested browser environments.
