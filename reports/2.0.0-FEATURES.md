# V2 implementation and scope

PR #1's six commits were merged intact into `feature/v2-learning-workbench` before feature work. Main baseline passed 17 engine and 26 packaged-browser checks; integrated PR baseline passed 18 and 27. No earlier fixes were discarded.

## Implemented

- 我 / 想 / 喝 / 咖啡 segmentation with known-compound preservation, dictionary coverage and a bounded segmentation cache. Unknown Intl word chunks are preserved rather than blindly split. Ordinary character/pinyin clicks select the word; Alt-click and expanded character buttons offer secondary character lookup.
- Punctuation appended to Hanzi rather than a fake pinyin syllable; common opening/closing Chinese quote/bracket handling. Source line breaks are normalized for compact captions rather than preserving subtitle author layout.
- Compact preview/pinned/context states, 32px action height, explicit Context, video-bound clamping/scrolling, focus on opened actions, Escape/focus restoration, arrow-key word navigation. Default subtitles remain three layers without a permanent toolbar; extra controls require ···.
- Watch/Learn, hover/click-only, optional Learn pause/resume; separate subtitle sizes, visibility, opacity, blur, spacing, alignment, position, system/serif/rounded fonts, tone colours, outline/shadow and reset. Preferences persist. Compact/Comfortable/Learning presets preserve custom settings.
- 6,500 selected licensed CC-CEDICT headwords, traditional aliases, marked-tone conversion, polyphonic phrase overrides and opt-in **limited common-phrase** sandhi. Unknown/ambiguous readings disclose uncertainty. No general natural-language disambiguation or full prosodic sandhi claim.
- Curated pattern-based context/grammar/examples for a small set of words, including 想 before an action. Unsupported contexts explicitly disclose dictionary-only coverage. Expanded cards expose traditional form, contextual notes, character buttons, Hear sentence and Replay sentence.
- Genuine localService Mandarin word/sentence speech, configurable speed/repetitions, no silent cloud fallback.
- Existing native text tracks, visible YouTube transcripts and SRT/VTT preparation retained: pause/resume/cancel, percentages/line counts, checkpoint/retry/cache reuse, explicit phase status and coverage limitations. Native track changes invalidate preparation. Cached pipeline version is bumped to prevent stale older processing results.
- Import two aligned Chinese/English SRT/VTT files together, reuse translations with no model, count matched/total and omit unmatched lines. Basic Hanzi language heuristic and timing tolerances are documented. Pairing does not guess across substantially misaligned files.
- Finite 1/2/3 replay at 0.5×/0.75×/1× with original-speed restoration; separate continuous looping. Shadowing listens once, pauses, hides/reveals English and continues on request. No recording/scoring.
- Vocabulary migration, example translation/traditional/source ID/timestamp/date/review history, sorting/recent/known/review filters; flashcards, meaning match, pinyin choice, listening choice and sentence recall. Existing edit/remove/search, formula-safe CSV/Anki TSV, JSON import/backup and simple review schedule remain.
- Sender-validated event-driven storage worker, serialized multi-tab mutations, bounded imports/cache, revision-based stale-write rejection after deletion, no added permissions, dependencies, accounts, advertising or trackers.
- Free ZIP packaging, reproducible package inspection/checksum, updated help/privacy/permission/license/installation documentation and screenshots.

## Deliberately limited / unfinished

- Offline audio transcription is disabled, with a practical investigation and future validation gates in `docs/OFFLINE_TRANSCRIPTION.md`. No model download controls or claimed Apple Silicon ASR performance are fabricated.
- No automatic pairing of existing bilingual HTML text tracks. Imported dual-file pairing is supported. No fuzzy transcript alignment or broad platform extraction.
- No estimated preparation completion time: model variability makes an ETA unreliable in the present implementation. Progress counts the available source lines, not an assumed entire video.
- No full dictionary, universal polyphonic/personal-name accuracy, general contextual semantics, automatic grammatical classification or independent native-Mandarin review. Pattern notes are developer-curated and conservative.
- No pronunciation assessment, speech input, sync, reminders, paid services, mandatory account or automatic updates for unpacked builds.
- Broad site/device/fullscreen acceptance and real 30/60/120-minute performance remain unverified. A player-container fullscreen test is separate from native video-only fullscreen/PiP support.
