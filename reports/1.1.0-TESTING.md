# Mandarin Lens 1.1.0 validation

28 October 2026. This report supersedes the version 1.0 release summary for the new changes; `TESTING.md` retains the original v1.0 evidence and limitations.

## Changes under test

- Prepared-caption storage usage and a cache-only clear that preserves saved vocabulary and appearance preferences.
- Immediate completed-line checkpoints on pause/cancel, including cancellation before the twentieth-line periodic checkpoint.
- Sentence looping on actual local media, manual seek release, and looping at the media's natural end.
- Replay respects timing offset; replay/loop controls are disabled while preparation is active.
- Escape closes transcript/settings/word details and restores focus without reopening the explanation.
- Cache eviction excludes discarded records when calculating the remaining budget.

The shipped permission set remains exactly `activeTab`, `scripting`, `storage`. No network/upload/capture capability or runtime dependency was added. Cache usage measures extension-local prepared records only, excluding Chrome-managed language packs. Clearing cache broadcasts cancellation before removing prepared records; saved words and settings remain. Cross-tab eviction accounting remains a best-effort target, not a transactional quota.

## Verification

`npm test`: 12/12 pure engine tests pass. The existing 10,000 seeded synthetic engine results remain baseline evidence; they were not recast as real users or browser sessions and the language/parser engine was not changed in this release.

`npm run check`: application syntax, manifest/package version agreement, exact permissions, CSP, selected unsafe code/network sinks and credential patterns pass. `git diff --check` passes. These checks are not an independent security audit.

`npm run test:browser`: the actual distributable ZIP is extracted into an isolated Chromium profile. The test-only manifest receives localhost access and an inert discovery worker; these never enter the release ZIP. Translation output is explicitly simulated for deterministic UI regression tests. Real original WebM playback verifies loop wrap, manual seek release and a loop that reaches the file's natural end. Cache-only clearing retains a real stored vocabulary entry, the selected font size and an active overlay. Cancellation after one of three subtitles persists that prefix, ignores the stale in-flight result and resumes to all three. Keyboard Escape and focus restoration are tested through actual key input. The report records the tested package hash and browser version.

`npm run test:real-extension` separately exercises Chrome's actual Translator in the extension isolated world, with owner-authorized language-pack downloads. Its results are recorded separately from the simulated rendering tests. It verifies both translation directions, preparation, seeking and cleanup; it does not establish broad translation accuracy or public-site compatibility.

No new universal claims are made for YouTube/Shorts, mobile, picture-in-picture, speech recognition, hardware support or long-session CPU/model memory. The earlier bounded YouTube sample had captions unavailable. No real beta participant feedback has been collected.

## Recorded final result

12 unit tests, 16 packaged Chromium checks (156.0.8078.4), and six real-model extension checks (installed Chrome 156.0.8078.48, Apple M5 Pro arm64) passed with zero page errors. The real model downloaded and initialized successfully on this run; earlier version 1.0 initialization failures remain a compatibility caveat rather than a guarantee of immediate setup.
