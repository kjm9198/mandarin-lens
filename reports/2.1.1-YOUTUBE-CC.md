# Mandarin Lens 2.1.1 — YouTube CC replacement

The existing extension waited for a manual YouTube CC toggle and displayed its own captions alongside YouTube’s text. The update enables the player’s CC feed automatically when Mandarin Lens starts and hides the native caption container only while replacement text is visible. The DOM source remains readable. Translation failure restores native text. Closing restores the previous CC switch when the extension changed it. Saved automatic-CC and replacement preferences default to on and are available in the popup and on-video settings. A visible message distinguishes a missing CC track from waiting for speech.
