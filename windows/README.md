# Kamihi Lens 4.3 — Windows Edition

Private Chinese study workspace and screen translation for Windows 10 & 11 (64-bit).

## Quick Start

1. Extract the `KamihiLens-4.3.0-Windows-x64.zip` archive into any folder (e.g. `C:\Users\<You>\KamihiLens`).
2. Double-click `KamihiLens.bat` to launch the application.
3. (Optional) Right-click `Install-Shortcut.ps1` and choose **Run with PowerShell** to create a Desktop shortcut.

## Features

- **Translate & Pinyin**: Instant lookup between Chinese (Simplified / Traditional), English, Vietnamese, and Polish. Generates tone-mark pinyin for Hanzi characters.
- **My Words (Dictionary)**: Save vocabulary, categorize words, hear native audio pronunciation, and import/export `words.json` (fully compatible with macOS Kamihi Lens).
- **Notepad with Recall Mode**: Markdown note taking, interactive checklists (`- [ ]`), journal templates, and study recall (hides translations until revealed).
- **7 Sproutsly-inspired Study Games (Play)**:
  - Meaning finder
  - Reverse recall
  - Listen & choose
  - Word builder
  - Meaning map
  - Memory match
  - Pinyin path
- **In-App Updates**: Click **Download update** in Settings anytime to fetch the latest release from `lens.kamihi.workers.dev`.
- **100% Offline & Private**: Zero external telemetry. All dictionary data and notes stay on your PC.
