Mandarin Lens 2.0

Free learning captions. No account, analytics, API key or caption uploads.

  1. Open a captioned video and turn on CC. Click the extension icon, then Start learning.
  2. On the video, press Start learning. This second click authorizes Chrome's local translation setup. A language pack may download; Chrome controls its size.
  3. Choose Prepare video first for accessible timed captions, or Import captions for SRT/VTT. On YouTube, open Show transcript before preparing. Only the available track is prepared; completeness is an estimate. Pause, resume or cancel preparation. Periodic local checkpoints allow retrying. Pausing or canceling also saves completed lines immediately.
  4. Compact is the default: 12px Chinese, 18px pinyin, 12px English, with no background box. Use the popup's Customize subtitles for sizes, layers, fonts, spacing, opacity, blur, position and timing. Positive timing offsets show prepared captions later. Press the small ··· control to open replay, loop, transcript and settings. Drag the compact control strip to reposition subtitles. Reset appearance in the popup restores the defaults.
  5. Hover shows a small word/pinyin/meaning tooltip above the word; clicking pins a compact card with Listen/Save and optional sentence context (Context). The explanation never grows the subtitle block. Select Chinese or pinyin to inspect a word; Learn mode can pause the video; Watch mode does not. Save words locally, pronounce with an installed local Mandarin voice, or open the timed transcript button to seek/replay prepared lines. The loop button repeats the selected prepared sentence; click again or seek outside it to stop. Escape dismisses a focused explanation, transcript or settings panel.
  6. Open Saved words to search, edit, review, import or export. JSON backup retains review data. CSV/Anki exports neutralize spreadsheet formulas. Again reviews in ten minutes; Good doubles the day interval; Easy triples it, up to 365 days.

Local installation and sharing

Extract the release ZIP into a permanent folder. In chrome://extensions, enable Developer mode, choose Load unpacked, and select the folder containing manifest.json. Send the ZIP and these instructions to a friend. Updates are manual. Back up vocabulary, replace files and Reload. This extension has no Chrome Web Store review or automatic updates.

Watch, learn and practise

Choose Watch or Learn in the popup. Advanced settings include click-only lookup, optional automatic resume, repeat count and speed, and local-voice controls. Alt-click a character for a separate lookup. In the ··· menu, Shadow listens once, pauses with English hidden, then lets you reveal English and continue. No speech is recorded or scored. Import two aligned Chinese and English SRT/VTT files together to reuse translations locally; unmatched lines are reported and omitted. Saved words includes offline practice exercises, sorting, review history in JSON backups, and Mark known.

Video selection and recovery

On pages with several videos, Mandarin Lens prefers the main visible player, with priority for fullscreen and playback. Live native captions follow the selected source language and ignore metadata tracks. Changing the selected video or its source clears previous prepared/imported captions. If local translation fails, press Start learning to retry; completed preparation lines are retained for resuming.

Availability and limitations

Local translation requires compatible desktop Chrome 138+ hardware and language packs. It is unavailable on mobile Chrome. There is no cloud fallback, microphone/tab-audio capture or audio transcription. Videos need accessible captions or a matching subtitle file. Site markup, cross-origin frames, Shorts, fullscreen and picture-in-picture vary; broad site compatibility is not certified.

Pinyin uses phrase overrides with a character fallback and can be wrong in unfamiliar contexts. The licensed 6,500-headword offline lexicon is a selected CC-CEDICT subset, not a full contextual dictionary. Missing meanings are disclosed. Local browser word lookup is a translation, not an authoritative grammar explanation.

Privacy and your data

Only activeTab, scripting and storage permissions. Preferences, up to 500 words/review schedules and recent prepared-caption checkpoints stay in extension-local storage. Prepared cache targets three records and about 4 MB; browser-managed language packs use additional disk space. Local data is not encrypted by this extension.

Clear prepared captions removes only the prepared cache and shows its storage usage, keeping words and preferences. Delete all my learning data in the popup clears stored preferences, vocabulary and prepared captions and closes active overlays. Exported files and Chrome language packs are managed separately. Closing the overlay stops its listeners, timers and translation processing.
