Mandarin Lens changes: selected a bounded subset using a documented common-character/project-glossary filter, converted it to JSON-shaped JavaScript data, retained at most three readings/four glosses per headword, removed cross-reference-only glosses and classifier lists, and limited gloss length. The selected/arranged dictionary data and these modifications remain CC BY-SA 4.0. Application code is separately MIT; the dictionary is not relicensed as MIT. No endorsement is implied.

The reproducible selector is scripts/build_lexicon.py. data/lexicon-provenance.json records the original source hash, export header, count and selection limits. It is not a full dictionary or official HSK word list. Multiple senses/readings do not establish a contextual interpretation.
