Quick Installation

No accounts, no cloud setup, completely offline-first.

🍎 macOS Installation

  1. Open DMG: Double-click KamihiLens-4.3.0-macOS-arm64.dmg.
  2. Drag to Applications: Move Kamihi Lens into your Applications folder.
  3. First Launch: This is an Apple Development preview build. If macOS prompts about an unidentified developer, open System Settings → Privacy & Security and click Open Anyway.
  4. Permissions: Grant Screen Recording when prompted so Lens can read screen text.

🪟 Windows Installation

  1. Extract Archive: Extract KamihiLens-4.3.0-Windows-x64.zip to any permanent folder.
  2. Run Launcher: Double-click KamihiLens.bat to launch the native app window.
  3. Desktop Shortcut: (Optional) Right-click Install-Shortcut.ps1 and choose Run with PowerShell.
  4. Updates: In-app Download update button automatically keeps your Windows installation fresh.
