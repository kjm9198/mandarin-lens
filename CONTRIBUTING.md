# Contributing

Open an issue describing a reproducible problem before broad changes. Keep runtime dependency-free where practical. Preserve existing storage keys and validate any migrations. Treat captions, imported files and model output as untrusted text. Never add remote translation, capture, analytics, broad host permissions or model downloads without clear opt-in and updated privacy disclosures.

Run `npm test`, `npm run simulate`, `npm run check`, `npm run build` and relevant browser checks. Report browser/OS, actual vs simulated model use and limitations. Do not commit real browsing history, private subtitles, credentials or model weights. Use tiny original fixtures. Security issues belong in private GitHub vulnerability reporting when available, following SECURITY.md.
