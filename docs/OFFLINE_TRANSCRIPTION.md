# Optional offline transcription investigation — 29 October 2026

V2 deliberately ships no recognizer, microphone request or tab capture. The popup option is disabled. Caption import remains available. This is a scoped limitation, not a simulated transcription feature.

A technically plausible future path is a **packaged**, pinned Transformers.js/ONNX Runtime Web worker plus multilingual Whisper-tiny weights chosen explicitly by the user. The [ONNX model card](https://huggingface.co/onnx-community/whisper-tiny) documents ASR compatibility. [Transformers.js WebGPU documentation](https://huggingface.co/docs/transformers.js/guides/webgpu) describes local GPU inference; device/browser support varies. This proves an available approach, not this extension's feasibility or a Mac benchmark.

Chrome's [remote-code guidance](https://developer.chrome.com/docs/extensions/develop/migrate/remote-hosted-code) requires packaged executable JS/WASM for MV3. Copying CDN example code would violate our current CSP and remote-code policy. Model data is different from executable code, but a download design still needs fixed URLs/revisions, integrity checks, bounded size and storage, cancellation, license review, and explicit informed user activation. The selected conversion's license and every packaged runtime notice must be verified before redistribution. No weights were downloaded during this investigation, and no trustworthy total download/RAM/CPU figure is claimed.

Start with user-selected local audio, decoded in a bounded offscreen/worker pipeline. Do not require microphone permission for imported audio. Tab audio is a separate explicit opt-in capture flow and permission review; never silently record. Do not assume cross-origin/DRM video audio can be read. Runtime workers must release audio buffers, GPU sessions, models and object URLs on cancel/navigation.

Release gates for a future experiment: pin model and runtime; verify licenses and exact download byte counts; package WASM locally; disclose storage/CPU estimates measured on Apple Silicon and a CPU fallback device; test Mandarin accuracy separately from English; limit duration/chunk memory; test abort/resume/cache deletion; deny remote executable fallback; verify zero audio uploads; make unsupported devices fail clearly. Keep the experiment isolated from caption playback. Ordinary browser SpeechRecognition is not treated as offline or private.

Additional primary-source checks: upstream [Whisper LICENSE](https://github.com/openai/whisper/blob/main/LICENSE) is MIT (copyright OpenAI, 2022). That is not by itself a complete audit of a particular ONNX conversion, runtime bundle or all redistribution notices. The [ONNX files listing](https://huggingface.co/onnx-community/whisper-tiny/tree/main/onnx), inspected on 29 October 2026, reports about 10.1 MB for an int8 encoder and 30.7 MB for an int8 merged decoder. Those rounded repository metadata sizes suggest roughly 40.8 MB for that weight pair alone, excluding tokenizer/config/runtime/WASM/cache overhead; they are not a measured total download, memory requirement or a promise that this exact pair runs in the extension. The whole folder contains multiple alternatives and should not be downloaded indiscriminately. Pinning, exact byte counts, conversion license verification, Mandarin quality and Apple Silicon/CPU measurements remain necessary before enabling a feature.
